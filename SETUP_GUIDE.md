# Expense Tracker App - Setup Guide

## Overview
This Flutter app allows users to track expenses and automatically sync them to Google Sheets. Each expense entry includes:
- **Unique ID** (generated by the app)
- **Label** (required)
- **Price** (required)
- **Category** (optional)
- **Note** (optional)
- **Expense Date** (required)
- **Timestamp** (automatically added when record is created)

## Firebase vs Direct Google APIs
**Firebase is NOT required!** This app uses:
- `google_sign_in` package for Google authentication
- `googleapis` package for direct Google Sheets API access

This is simpler and doesn't require Firebase setup.

## Prerequisites
1. Flutter SDK installed
2. Google Cloud Project with Sheets API enabled
3. OAuth 2.0 credentials configured

## Setup Instructions

### Step 1: Install Dependencies
```bash
flutter pub get
```

### Step 2: Google Cloud Console Setup

1. **Create a Google Cloud Project** (if you don't have one):
   - Go to [Google Cloud Console](https://console.cloud.google.com/)
   - Create a new project or select an existing one

2. **Enable Google Sheets API**:
   - Navigate to "APIs & Services" > "Library"
   - Search for "Google Sheets API"
   - Click "Enable"

3. **Create OAuth 2.0 Credentials**:
   - Go to "APIs & Services" > "Credentials"
   - Click "Create Credentials" > "OAuth client ID"
   - If prompted, configure the OAuth consent screen first:
     - Choose "External" (unless you have a Google Workspace)
     - Fill in required fields (App name, User support email, Developer contact)
     - Add scopes: `https://www.googleapis.com/auth/spreadsheets`
     - Add test users (your email) if in testing mode
   - Create OAuth client ID:
     - Application type: **Android** (for Android app)
     - Application type: **iOS** (for iOS app)
     - Application type: **Web application** (for web/desktop testing)

4. **Configure OAuth Client for Android**:
   - Package name: `com.example.expensesheet` (check your `android/app/build.gradle`)
   - SHA-1 certificate fingerprint (get it using):
     ```bash
     cd android
     ./gradlew signingReport
     ```
   - Copy the SHA-1 from the output

5. **Configure OAuth Client for iOS**:
   - Bundle ID: Check your `ios/Runner.xcodeproj` or `ios/Runner/Info.plist`
   - Usually: `com.example.expensesheet`

### Step 3: Android Configuration

1. **Update `android/app/build.gradle`**:
   - Ensure your package name matches the OAuth client configuration

2. **Add SHA-1 to Google Cloud Console**:
   - Use the SHA-1 from Step 2.4

### Step 4: iOS Configuration

1. **Update Bundle ID** in Xcode:
   - Open `ios/Runner.xcodeproj` in Xcode
   - Ensure Bundle Identifier matches OAuth client configuration

2. **Add URL Scheme** (if needed):
   - The `google_sign_in` package handles this automatically

### Step 5: Create a Google Sheet

1. Create a new Google Sheet
2. Copy the Spreadsheet ID from the URL:
   - URL format: `https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit`
   - The `SPREADSHEET_ID` is the long string between `/d/` and `/edit`

3. Share the sheet with the Google account you'll use to sign in
   - Or make it accessible to anyone with the link (for testing)

### Step 6: Run the App

```bash
flutter run
```

## How to Use

1. **Sign In**:
   - Tap "Sign in with Google"
   - Select your Google account
   - Grant permissions for Google Sheets access

2. **Enter Spreadsheet ID**:
   - Paste your Google Sheet ID in the text field
   - This is a one-time setup (you may want to save it in app preferences)

3. **Add Expense**:
   - Fill in the expense form:
     - **Label**: Name of the expense (e.g., "Groceries")
     - **Price**: Amount spent
     - **Category**: Optional category (e.g., "Food", "Transport")
     - **Date**: Select the expense date
     - **Note**: Optional additional notes
   - Tap "Add Expense to Sheet"
   - The app will automatically:
     - Generate a unique ID
     - Add a timestamp
     - Append the row to your Google Sheet

## Google Sheet Format

The app creates a table with the following columns:
- **ID**: Unique identifier (UUID)
- **Label**: Expense label
- **Price**: Amount (formatted as decimal)
- **Category**: Category (empty if not provided)
- **Note**: Notes (empty if not provided)
- **Expense Date**: Date in YYYY-MM-DD format
- **Timestamp**: Full timestamp when record was created (ISO 8601)

## Troubleshooting

### "Sign in failed" or "Access denied"
- Ensure OAuth consent screen is configured
- Check that your email is added as a test user (if in testing mode)
- Verify SHA-1 certificate matches in Google Cloud Console

### "Sheets API not initialized"
- Make sure you've signed in successfully
- Check that Google Sheets API is enabled in Google Cloud Console

### "Error adding expense"
- Verify the Spreadsheet ID is correct
- Ensure the Google account has edit access to the sheet
- Check that the sheet exists and is accessible

### Android Build Issues
- Run `flutter clean` and `flutter pub get`
- Ensure `minSdkVersion` is at least 21 in `android/app/build.gradle`

## Security Notes

- Never commit OAuth credentials to version control
- For production, use proper credential management
- Consider storing Spreadsheet ID in secure storage (shared preferences with encryption)
